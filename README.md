# validador-nc-cnc

Um aplicativo desenvolvido em Python com interface gráfica (CustomTkinter) para validar arquivos de G-code (`.nc`, `.tap`, `.txt`) gerados pelo Vectric Aspire/VCarve. O programa realiza a checagem cruzada entre a espessura descrita no nome do arquivo, os parâmetros de Z do material e o posicionamento correto da origem do eixo Z em relação à mesa da máquina (Base da Máquina).

---

## ⚙️ Pré-requisitos para rodar

Para executar este programa, você precisa ter instalado no seu computador:

1. **Python** (versão 3.8 ou superior recomendada).
2. A biblioteca gráfica **CustomTkinter**.

---

## 📦 Instalação de Dependências

Abra o seu terminal (Prompt de Comando ou PowerShell) e instale o CustomTkinter executando o seguinte comando:

```bash
pip install customtkinter

# validador-nc-cnc

A Python application with a graphical interface (CustomTkinter) designed to validate G-code files (`.nc`, `.tap`, `.txt`) generated by Vectric Aspire/VCarve. The program performs cross-checks between the thickness indicated in the filename, the material's Z-axis parameters, and the correct positioning of the Z-axis origin relative to the machine bed (Machine Bed Zero).

---

## ⚙️ Prerequisites

To run this program, you need to have the following installed on your computer:

1. **Python** (version 3.8 or higher recommended).
2. The **CustomTkinter** GUI library.

---

## 📦 Installing Dependencies
